# Пояснительная записка — LessonFlow

**LessonFlow** — персональный интегратор для онлайн-преподавателя. Он собирает расписание уроков и все рабочие ссылки одного дня в едином интерфейсе.

Вместо переключения между таблицей, Zoom/Google Meet, Quizlet, YouTube, Google Docs, GitHub-играми, Baamboozle и домашними заданиями преподаватель открывает одну страницу. На ней отображается мини-план каждого урока: время, ученик, уровень, тема, длительность и последовательность ресурсов.

Сайт автоматически формирует до шести карточек уроков на выбранный день. При открытии карточки запускается Lesson Mode: ресурсы расположены по порядку, открываются в один клик, а выполненные этапы можно отмечать как завершённые.

Источником данных служит таблица в Яндекс Документах / на Яндекс Диске. Преподаватель редактирует только таблицу. GitHub Actions автоматически скачивает её, преобразует данные и обновляет сайт. Благодаря этому расписание и ссылки не нужно вручную дублировать в коде.

Инструмент размещается на GitHub Pages и работает как статический сайт. Интерфейс адаптируется под компьютер и мобильное устройство, имеет светлую и тёмную тему и не требует отдельного сервера для просмотра.

**Практическая польза:** LessonFlow сокращает количество открытых вкладок и ручных действий перед уроком, помогает быстро видеть весь рабочий день и хранит материалы каждого занятия в одном понятном маршруте.
