ПОЯСНИТЕЛЬНАЯ ЗАПИСКА — LESSONFLOW

LessonFlow — персональный интегратор для онлайн-преподавателя. Инструмент автоматически формирует красивый дневной dashboard из рабочего листа PLAN в Яндекс Таблице.

В PLAN преподаватель хранит время урока, ученика, уровень, тему, последовательность этапов, ссылки, изображения упражнений и аудио. В одной активности могут одновременно использоваться интернет-ссылка, до двух изображений и аудиотрек.

В той же книге могут находиться дополнительные листы GROUPS и MY BASE. Они используются как личные справочники преподавателя, но синхронизатор LessonFlow читает только лист PLAN и не передаёт содержимое остальных листов на сайт.

GitHub Actions автоматически получает актуальную версию таблицы, извлекает данные и изображения из XLSX, при необходимости скачивает аудио и обновляет data/lessons.json. Если источник не менялся, лишний commit не создаётся. Синхронизация запускается автоматически каждые 10 минут или вручную.

Для финального использования предусмотрен приватный режим через Yandex Disk REST API и OAuth-токен, который хранится в GitHub Secrets и не попадает в код сайта.

Интерфейс показывает 5–6 карточек уроков на день, текущий и следующий урок, общее время и количество материалов. В Lesson Mode преподаватель открывает ссылки, увеличивает страницы учебника, воспроизводит аудио и отмечает выполненные этапы.
